【补丁·首页——登录不归你】

打开网站首先出现的必须是登录，但登录页和鉴权由「个人中心」做（/login）。

你只做登录成功之后的东西：
1. 不要在 public/index.html 做用户名密码表单。
2. 未登录时如果用户打到 / ，应被鉴权中间件送到 /login（中间件由个人中心加）。你不要绕过它。
3. 已登录：工作台 + 7 项导航；顶栏显示当前用户名，并提供「个人中心」「退出」（退出调用 POST /api/auth/logout 后跳转 /login）。
4. 导航仍是：首页、数据中心、沈子晗运营中心、韩梦凯运营中心、人员管理、版本发布中心、个人中心。

【验收】未登录打开 / 看不到 7 张卡片；登录后才看到工作台。
