# 发版权只在版本发布中心

其他 Agent **禁止** SSH 到 ECS、禁止 `push-xingmai-to-ecs.sh`、禁止 `systemctl restart`、禁止 docker 上生产。

做完功能后，必须输出一份 **发布文档**（按下面模板）。用户（主脑）把文档转给「版本发布中心」并下令后，才允许发版。

## 发布文档模板

```
【发布文档】
模块：
版本号建议：
PR / 分支：
改动文件列表：
用户可见变化：
本机如何验收：
上线后如何验收：
依赖（必须先上线的其他模块）：
回滚办法：
风险：
是否需要重启 mengkai.service：是/否
```
