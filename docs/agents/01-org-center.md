# 组织中心（智能体纪律）

登录不上生产站时先读 `docs/agents/00-prod-admin.md`。交单模块名仍是 **组织中心**，申请人、来源仍是 **罗成运营部主脑**。

## 不接钉钉

组织中心继续不接钉钉。

- 不要改 `people` 表加钉钉字段（如 userid、unionid、openId、钉钉手机号）
- 不要同步钉钉通讯录
- 不要为了对齐钉钉去改花名册、管辖或店铺主数据

在职与店权只认组织中心自己的花名册和管辖。钉钉通讯录不是源。

## 手维护

花名册和店权仍手维护：页面录入、导入或单元格修改。智能体只读，禁止代写花名册、禁止把别的模块名单灌进来。

## 假勤不在这里

假勤、打卡、调休、加班归 **智能人事**。组织中心不做考勤、不做请假加班，也不为这些去接钉钉。

主框架已经有智能人事入口（`/hr`）。不要在组织中心再铺菜单、第六个页签，也不要往权限目录加「智能人事」。组织中心五个功能仍是：店铺主数据、成员管理、责权、权限、改动日志。
